CINOVA CONNECTION

Connect TMDB

Paste your TMDB API Key (v3) below. It will be saved only in this browser on this device. Do not paste your key into GitHub or share it publicly.

Security note: CINOVA is a public static website. A key entered here is not embedded in the published HTML, but browser-based API requests can still expose it to someone inspecting network traffic. For a production public app, use a small server-side proxy and follow TMDB's terms and attribution requirements.
